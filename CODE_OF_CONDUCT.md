# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive in issues, pull requests and every other project space.
Harassment, personal attacks, discriminatory language and publishing other people's private
information are not accepted.

## Reporting

Report unacceptable behaviour privately to the maintainer through the contact details on the
maintainer's [GitHub profile](https://github.com/gitababa). Reports are handled confidentially.

## Enforcement

The maintainer may edit or remove comments, commits, issues and other contributions that break
this code, and may temporarily or permanently ban anyone from the project's spaces, following
the Contributor Covenant's enforcement guidelines.
